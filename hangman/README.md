#  Bio-Hangman
A bioinformatics-themed twist on the classic hangman game.

## How it works:
- **Backend:** Python logic selects biological terms from specialized libraries (Genetics, Proteomics, etc.).
- **Frontend:** Interactive JavaScript interface.
- **Theme:** Instead of a hangman, players must guess the word before their cell runs out of **ATP**.

## Learning Objectives:
- Familiarity with biological nomenclature.
- Understanding of cellular components and lab techniques.
